# Google Play app access

The application requires an account. Supply Google Play review with a dedicated, reusable test account that remains active for the entire review.

## Instructions for the reviewer (English)

1. Open DuelRush and tap **Sign in**.
2. Enter the review username and password supplied in the private Play Console fields.
3. No email verification or one-time code is required for this existing review account.
4. The learning, duel, ranking, profile, friends, achievements, listening, and vocabulary areas are available from the main navigation.
5. Microphone permission is optional and is requested only when the reviewer starts a pronunciation exercise.

## Private Play Console fields

Username: [create a dedicated review account]

Password: [enter only in Play Console; never commit it to Git]

Additional instructions: The account has access to all standard user features. Online matchmaking may use a practice opponent if another user is not immediately available.
